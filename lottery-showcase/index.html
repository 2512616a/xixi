开源抽奖

五个仍在维护、可以自己部署的抽奖项目。点进去就能用自带的示例数据抽一次。不需要注册，也没有密钥。

  1. 01 · 大转盘 / 九宫格 / 老虎机

    lucky-canvas

    点中间的「开始抽奖」，转盘停下后显示红包结果。同页可以打开官方的九宫格和老虎机调试页。

    开始转盘 →
  2. 02 · 3D 球体年会抽奖

    年会抽奖

    先点「进入抽奖」，再点「开始抽奖」。球转起来后点「结束抽奖」，中奖的人名会亮出来。名单是项目自带的示例 Excel。

    进入年会现场 →
  3. 03 · 可配置 3D 年会抽奖

    log-lottery

    如果提示没有名单，点「使用默认数据」或 Use Default Data。然后点「进入抽奖」「开始」「抽取幸运儿」。

    打开 log-lottery →
  4. 04 · 年会大屏

    年会大屏抽奖

    后台密码是页面上写的 appinn。登录后打开「批量导入」，贴入姓名和部门，点「执行导入」，再点绿色的「开始」和「停止」。

    打开后台 →
  5. 05 · 纯前端 3D 舞台

    lottery-3d

    打开就是示例名单。点「开始抽奖」，倒计时结束后点「停」，三等奖名单会翻出来。

    打开 3D 舞台 →
